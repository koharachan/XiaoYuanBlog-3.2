## 本站信息

如果希望交换友链，请先在自己的网站添加本站，再通过留言板提交申请。可以使用下面这组信息：

```yaml
站点名称: 小原blog
站点描述: 记录博客搭建、服务器运维、AI 实验与日常观察
站点链接: https://blog.meowhead.cn
头像链接: https://pan.qzyun.net/f/zVviw/%E5%A4%B4%E5%83%8F.jpg
```

## 申请方式

请在[留言板](/guestbook/)留下以下信息，不需要公开邮箱或其他私人信息：

```text
站点名称：
站点描述：
站点链接：
头像链接（可选）：
```

## 收录规则

1. 申请前请先添加本站链接，并确保链接可以正常访问。
2. 网站应使用 HTTPS，内容以原创或有明确来源的整理为主。
3. 不收录含恶意代码、钓鱼、强制弹窗或明显违法违规内容的站点。
4. 长期无法访问、停止维护或内容方向发生明显变化时，可能会暂时移除；恢复后可以重新申请。

友链列表与页面文案分别维护，页面展示的站点会以站内配置为准。
